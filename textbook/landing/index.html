Web Application Security

Secure Engineering, Threat Modeling, and Scoped Testing

Written by Yau Ka Cheung, M.S., this textbook bridges web programming and security engineering—teaching how web applications fail across parser boundaries, browser contexts, identity flows, and backend APIs, and how engineers defend and contain real intrusions.
