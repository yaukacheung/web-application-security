# Week 8 Lecture Notes

## Session Title

Midterm Review and Applied Practical

## Learning Goals

Students should be able to explain methodology review, evidence quality, risk rating, remediation mapping, professional communication and apply them to complete a scoped practical assessment under exam conditions.

## Instructor Preparation

- Start the local lab stack before class if a live demo is planned.
- Prepare a clean browser profile and proxy configuration.
- Choose one low-risk demonstration path that stays inside the assigned target.
- Prepare an example finding with one strong evidence item and one weak evidence item.

## Key Teaching Points

### Technical Core

The technical center of this week is methodology review. Students should connect the concept to concrete request and response behavior instead of treating it as abstract vocabulary.

### Risk Connection

Unclear evidence weakens even technically correct findings. Ask students to explain the affected asset and the failed security assumption in plain language.

### Defensive Frame

Security testing is useful only when it leads to better controls. For each finding, push students to name the control location, the expected behavior, and a regression test.

## Suggested Discussion Prompts

- What evidence would prove that this issue affects a real asset?
- Where should the application enforce the defensive control?
- What would make this issue higher or lower severity?
- How could a developer accidentally reintroduce this issue later?

## Lab Bridge

The lab asks students to complete a scoped practical assessment under exam conditions using Assigned local target. Remind students to stay inside the written scope and to capture only the evidence needed for the claim.
