# Week 12 Student Lab

## REST and JSON API Testing

## Target

NodeGoat and Juice Shop

## What You Will Practice

You will test API validation, authorization, and rate assumptions. Work only inside the assigned local lab environment.

## Tasks

1. Build an endpoint inventory
2. Inspect JSON requests
3. Test role and object boundaries
4. Recommend API controls

## Evidence To Submit

- Scope statement
- Target and role used
- Baseline behavior
- Reproduction or observation steps
- Minimal screenshots or request/response excerpts
- Impact explanation
- Remediation recommendation
- Limitation or uncertainty

## Safety Reminder

Do not test outside the assigned local target. Do not include real passwords, complete session tokens, or unrelated personal data in your submission.
