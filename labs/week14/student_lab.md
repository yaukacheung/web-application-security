# Week 14 Student Lab

## Detection Engineering for Web Attacks

## Target

Local lab stack

## What You Will Practice

You will design useful detection notes for web attack behavior. Work only inside the assigned local lab environment.

## Tasks

1. Define key events
2. Write detection logic in plain language
3. Create a triage checklist
4. Explain WAF limitations

## Evidence To Submit

- Scope statement
- Target and role used
- Baseline behavior
- Reproduction or observation steps
- Minimal screenshots or request/response excerpts
- Impact explanation
- Remediation recommendation
- Limitation or uncertainty

## Safety Reminder

Do not test outside the assigned local target. Do not include real passwords, complete session tokens, or unrelated personal data in your submission.
