# Student Guide

## How to Use This Repository

Start with the syllabus, setup guide, and the [Course Textbook](../textbook/README.md) (`textbook/online/index.html` for the web edition). Each week, read the assigned textbook chapter, review the lecture slides, complete the lab manual, and take the quiz.

## Lab Report Habit

For every lab, record (using the template in `textbook/chapters/appendix-b-penetration-testing-report-template.md`):

- Scope
- Target
- Baseline behavior
- Test steps
- Evidence
- Impact
- Remediation
- Limitations

## Safety Reminder

Only test the local targets assigned by the course. Do not test public systems, university systems, classmates' devices, or any target without written permission.

## Evidence Reminder

Good evidence is specific and minimal. Do not include passwords, full session tokens, unrelated personal data, or material outside the assignment scope.
