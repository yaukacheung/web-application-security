# Capstone Penetration Testing Project

## Overview

Students complete a scoped penetration test against an assigned local intentionally vulnerable application. The project emphasizes planning, ethical conduct, evidence quality, risk rating, remediation, and professional reporting.

## Approved Targets

- OWASP Juice Shop
- DVWA
- WebGoat
- Mutillidae II
- NodeGoat

## Deliverables

- Rules of engagement and scope statement
- Attack surface inventory
- Test plan
- Findings report with evidence
- Executive summary
- Remediation roadmap
- 8-10 minute presentation

## Minimum Finding Requirements

Submit at least four validated findings:

- One authentication, authorization, or session issue
- One input handling or injection issue
- One browser, API, or client/server boundary issue
- One design, logging, dependency, or SDLC issue

## Required Finding Format

See `textbook/chapters/14-penetration-testing-methodology-and-reporting.md` and `textbook/chapters/appendix-b-penetration-testing-report-template.md` for the full report template. Each finding must include:

- Title
- Severity
- Affected asset
- Scope confirmation
- Description
- Reproduction steps
- Evidence
- Impact
- Remediation
- Regression test recommendation
